# Сортировщик файлов

## Задача заказчика
Учебной части нужно быстро приводить в порядок папки с отчётами, изображениями, таблицами, архивами и кодом. Программа сортирует файлы по типам, сначала показывает план, а перемещает их только после подтверждения пользователя.

## Стек
Python 3.10+, стандартные библиотеки `pathlib`, `shutil`, `argparse`, `csv`, `unittest`.

## Как запустить
Откройте терминал в папке проекта:

```bash
python src/main.py data/demo_folder
```

Программа покажет план и спросит подтверждение. Чтобы выполнить сортировку без вопроса:

```bash
python src/main.py data/demo_folder --yes
```

## Как запустить тесты

```bash
python -m unittest discover -s tests -v
```

## Тестирование
Проверены:
- определение категории по расширению;
- пустая папка;
- построение плана без перемещения файлов;
- фактическое перемещение и создание журнала;
- обработка несуществующей папки.

## Ограничения MVP
Сортируются только файлы из корня выбранной папки, вложенные папки программа не обходит. Перед массовой сортировкой рекомендуется сделать резервную копию. Отмена уже выполненного перемещения пока не реализована.
